# إضافة موعد — المخزون والمراجعة

## الهدف
تحديد المخزون اختياريًا ومراجعة بيانات الموعد قبل الحفظ.

## العناصر
- الخطوة 3 من 3.
- كمية المخزون الحالية.
- مفتاح تنبيه انخفاض المخزون.
- حد التنبيه.
- ملاحظات اختيارية.
- ملخص بيانات الدواء والمواعيد مع أزرار تعديل.
- زر «حفظ».

## السلوك
- الحفظ يعيد المستخدم إلى «اليوم» مع ظهور الموعد في العرض المؤقت.
- تعديل كل قسم يعيد إلى الخطوة المناسبة.
- البيانات لا تُرفع ولا تعتمد على الإنترنت.

## التجاوب والوصولية
محتوى قابل للتمرير، أزرار واضحة، دعم RTL/LTR، ومنع تداخل الملخص مع زر الحفظ.

## الأصول
لا توجد أصول خارجية؛ تستخدم Icons من Material.

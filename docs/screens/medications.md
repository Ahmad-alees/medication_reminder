# شاشة أدويتي — Medications

## الهدف
عرض الأدوية والمواعيد المرتبطة بها والمخزون المتبقي، مع نقطة دخول واضحة لإضافة موعد جديد.

## العناصر
- عنوان «أدويتي».
- حقل بحث عن دواء.
- بطاقة تنبيه الأدوية القريبة من النفاد.
- عدد الأدوية.
- بطاقات الدواء، وكل بطاقة تعرض:
  - الاسم والتركيز.
  - عدد مرات التكرار.
  - أوقات التذكير.
  - كمية المخزون المتبقية.
  - مؤشر مخزون.
- زر «إضافة موعد».
- التنقل السفلي.

## السلوك
- البحث يصفّي القائمة حسب اسم الدواء.
- الضغط على بطاقة الدواء يفتح تفاصيل الدواء.
- الضغط على تنبيه المخزون يفتح قائمة الأدوية منخفضة المخزون.
- زر «إضافة موعد» يفتح مسار الإضافة الموثق سابقًا.
- لا يعتمد العرض على الإنترنت.

## التصميم المتجاوب
- محتوى رأسي قابل للتمرير.
- بطاقات بعرض الشاشة مع نصوص قابلة للتمدد.
- مؤشر المخزون لا يعتمد على اللون وحده؛ يعرض الكمية كنص.
- دعم RTL/LTR والوضعين النهاري والداكن.
- منع قص أسماء الأدوية أو أوقات التذكير الطويلة.

## الوصولية
- حقل البحث له label واضح.
- بطاقة كل دواء عنصر قابل للوصول مع الاسم والمخزون.
- تنبيه المخزون يصف الحالة نصيًا.
- زر الإضافة قابل للوصول بقارئ الشاشة.

## الأصول
لا توجد أصول خارجية مطلوبة؛ تستخدم Icons من Material.

## خارج نطاق هذه المرحلة
- قاعدة البيانات المحلية.
- تعديل أو حذف الدواء فعليًا.
- خصم المخزون عند تسجيل الجرعة.
- المزامنة أو رفع البيانات.

## معيار القبول
- يفتح التبويب من التنقل السفلي.
- تظهر قائمة الأدوية والبحث والتنبيه.
- يعمل التصفية بالبحث.
- يعمل زر «إضافة موعد».
- يعمل التصميم في RTL/LTR والنهاري/الداكن دون overflow.
